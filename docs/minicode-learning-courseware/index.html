MiniCode 本地 AI Coding Agent 学习课件

参考 EduRAG 课件的组织方式，本课件按“项目全景、源码阅读路线、核心模块深度讲解、评估与复盘”的顺序拆解 MiniCode。

Agent Runtime Tool Calling Memory Context Compaction Permission Safety Harness Eval

课程定位

这份课件不把 MiniCode 当成普通 CLI 工具讲，而是把它当成一个本地 Agent Runtime 来学习：模型只是推理核心，真正难点在于如何让模型在真实代码仓库中安全、连续、可恢复、可评估地工作。

因此课程会同时讲清技术栈、代码结构、执行流程和设计取舍。你可以用它学习源码，也可以把其中的“项目亮点和难点”转化成简历与面试讲法。
