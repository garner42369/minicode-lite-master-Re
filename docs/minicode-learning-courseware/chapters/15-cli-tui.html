5.3 CLI/TUI：本地产品交互面

学习目标

  • 理解 MiniCode 不只有后端逻辑，也有本地产品交互。
  • 看懂 slash commands 和 TTY app 的职责。
  • 理解为什么 transcript 是 Agent 产品的重要界面。

CLI Commands

cli_commands.py 提供大量 slash commands，例如：

  • /help
  • /tools
  • /status
  • /cost
  • /context
  • /memory
  • /config
  • /sessions
  • /session
  • /session-replay
  • /checkpoints
  • /rewind-preview
  • /rewind
  • /model
  • /mcp
  • /permissions
  • /read
  • /write
  • /edit
  • /patch
  • /cmd

这些命令的意义是：用户不必每件事都交给模型，可以直接查询和控制 Agent runtime。

TTY App

tty_app.py 和 minicode/tui/ 实现交互式终端界面，包含：

  • 屏幕状态。
  • transcript 渲染。
  • 工具输出折叠。
  • 审批弹窗。
  • 后台 agent 线程。
  • 键盘输入处理。
  • session autosave。
  • slash command 本地处理。

Transcript

transcript 是用户理解 Agent 行为的窗口：

  • Agent 说了什么。
  • 调用了哪些工具。
  • 工具结果是什么。
  • 哪些步骤需要审批。
  • 是否出现 checkpoint。
  • readiness 是否阻塞。

这让 Agent 从“黑盒模型”变成“可观察工作台”。

CLI/TUI 和 Agent Loop 的关系

CLI/TUI 不直接决定任务怎么做，它负责：

展示状态
接收输入
处理本地命令
发起 run_agent_turn
显示工具和模型输出
保存 session

真正的智能执行仍然在 Agent Loop 中。

本章小结

MiniCode 的 CLI/TUI 是本地 Agent 产品面。它让用户能看到、控制和恢复 Agent 的工作过程，而不只是看到最后一段回答。
